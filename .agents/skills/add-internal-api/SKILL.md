# 내부 API 추가

저장소 루트의 `AGENTS.md`와 `.claude/skills/add-internal-api/SKILL.md`를 읽고 원본 절차 전체를 따른다. 경로는 저장소 루트 기준이다.

이 스킬은 아직 틀이다. `docs/conventions.md`와 해당 계약의 합의 상태를 먼저 확인하고, 미합의 계약으로 구현하지 않는다. 실제 구현에서 절차를 보완할 때는 원본을 수정하고 이 진입점은 연결만 유지한다.
