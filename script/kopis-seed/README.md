# 11월 KOPIS 공연 시드

2026-11-04에 확보한 KOPIS 11월 공연 중 홀·객석 수, 장르·러닝타임·관람 안내, 전석 유료 가격과 요일별 시간표를 확인한 1,116건이다. [seed-kopis.sql](../../backend/performance-service/src/main/resources/db/seed-kopis.sql)은 기본 local 시드 다음에 자동 실행된다. 실행에 API 키나 네트워크가 필요하지 않다.

| KOPIS 데이터 | 생성한 값 |
|---|---|
| 시설 상세의 홀 ID·홀 객석 수 | 같은 홀을 한 번만 등록하고 객석 수만큼 A구역 좌석을 만든다. 열마다 최대 10석이며 실제 배치도가 아니다. |
| 공연별 전석 가격 | 홀마다 일반 등급 한 개를 두고 가격은 공연별로 연결한다. |
| 기간·요일·시각 | 공연의 **전체 기간**에서 해당 요일·시각을 전개하고 중복 시각을 제거한다. 개별 회차의 휴연·변동을 보증하지 않는다. |
| 판매 기간·판매자 | 예매 오픈·마감과 판매자 1001은 테스트값이다. 공개 시각은 원본 최초 등록 시각을 사용한다. |

공연 조회용 시드다. 추가 1,114건의 회차는 PENDING으로 두고 좌석 준비 예약 시각은 비워 둔다. 기본 local 기동이 연동 서비스로 대량의 좌석 준비 요청을 보내는 것을 방지한다. 기존 두 샘플 PF305396·PF305424는 기존처럼 좌석 준비 대상이다. NOL 확인 여부는 좌석 준비 대상 선정과 무관하다.

### NOL 확인 기록

[공연별 CSV](nol-status.csv)는 같은 시드의 부속 자료다. 판정 시점은 2026-11-04이며 실시간 판매 또는 잔여 좌석 여부는 나타내지 않는다.

| 상태 | 건수 | 의미 |
|---|---:|---|
| PAGE_MATCHED | 3 | 상품 페이지의 작품·장소·기간이 KOPIS와 일치 |
| PAGE_UNAVAILABLE | 3 | 상품 페이지 대조를 시도했지만 확인하지 못함 |
| LINK_ONLY | 595 | KOPIS에 NOL 링크가 있고 상품 페이지는 미검증 |
| NO_LINK | 515 | 수집한 KOPIS 원본에서 NOL 링크를 찾지 못함 |

### 재생성

저장된 원본 스냅샷에 대해 저장소 루트에서 실행한다.

~~~text
python script/kopis-seed/generate.py .local/kopis-seed/survey-20261101-30
~~~

입력은 공연별 판정 파일 eligibility.csv와 KOPIS 공연·시설 상세 XML이다. 출력 SQL·CSV는 저장소에 포함하므로 팀원은 시연·테스트 전에 원본을 수집하거나 재생성할 필요가 없다.
