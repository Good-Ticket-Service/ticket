# 팀 결정사항

서비스 범위, 정책, 통신 방식, 측정 환경처럼 여러 도메인에 걸친 결정을 모은다. 한 도메인 안의 결정은 그 도메인 폴더에, 기술 선택의 이유와 대안도 여기에 한 줄로 남기고, 길면 근거 문서를 링크한다.

| 상태 | 뜻 |
|---|---|
| 제안 | 누군가 올렸고 아직 합의 전이다 |
| 확정 | 팀이 합의했다. 근거(회의록·이슈)를 남긴다 |
| 폐기 | 다른 결정으로 바뀌었다. 바꾼 결정 번호를 적는다 |

| # | 결정 | 상태 | 근거 | 날짜 |
|---|---|---|---|---|
| P1 | 문서는 도메인 단위 폴더에 두고, 서비스·모듈 간 계약은 `docs/shared/`에 두어 계약 변경 흐름으로만 바꾼다 | 제안 | #3 | 2026-10-26 |
