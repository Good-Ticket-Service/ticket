# 부하 테스트 기록

측정할 때마다 파일 하나를 남긴다. 파일 이름은 `YYYY-MM-DD-{도메인}-{시나리오}.md`이고 양식은 [template.md](template.md)다. 개선 전후를 비교하려면 측정 환경과 시나리오를 같게 맞춘다.

| 날짜 | 도메인 | 시나리오 | 처리량(RPS) | 평균 응답 시간 | 성공률 | 파일 |
|---|---|---|---|---|---|---|
| | | | | | | |

도메인별 실험 계획은 그 도메인 문서에 둔다(예: [payment/experiments.md](../payment/experiments.md)).
